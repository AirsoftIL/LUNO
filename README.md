# LUNO — האתר כולל מעקב משלוחים

חלצו את ה־ZIP והעלו את כל התוכן לשורש מאגר GitHub של האתר: index.html, classic.html, extreme.html, tracking.html והתיקיות assets, images, videos וכל יתר הקבצים. אין להעלות רק את קובצי ה־HTML.

ב־Settings → Pages בחרו Deploy from a branch, הענף main והתיקייה / (root).

דף tracking.html מציג מעקב בעיצוב LUNO באמצעות שרת האתר. החיבור לנתוני משלוחים עדיין לא הופעל: נדרש חשבון API ומפתח סודי בשרת, ורישום מספרי המשלוח עם התג LUNO. כרגע הדף מציג הודעה ברורה שהמעקב בהקמה ופנייה לצוות. אין כאן קישור לאתר מעקב חיצוני. שרת האתר של LUNO חייב להישאר פעיל גם כשמעלים ל־GitHub. כתובת GitHub הנתמכת כרגע: https://airsoftil.github.io. פרטי ההגדרה בקובץ TRACKING-SETUP.md.

כל קישורי התשלום, המוצרים, הסרטון וההתאמות הקודמות נשמרו.
