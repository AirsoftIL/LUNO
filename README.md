# LUNO — האתר המעודכן

## העלאה ל־GitHub

1. חלצו את קובץ ה־ZIP.
2. במאגר האתר ב־GitHub לחצו Add file → Upload files.
3. העלו את כל התוכן שחולץ: index.html, classic.html, extreme.html, תיקיות assets ו־images ושאר הקבצים. העלו את התוכן לשורש המאגר, לא בתוך תיקייה נוספת.
4. לחצו Commit changes.
5. ב־Settings → Pages בחרו Deploy from a branch, הענף main והתיקייה / (root), ושמרו.

הקובץ index.html קצר בכוונה: הקוד והעיצוב נמצאים בתיקיית assets. חובה להעלות את כל הקבצים יחד.

האתר כולל 27 קישורי תשלום לפי שילובים עד 6 משקפיים. מעל 6 משקפיים ממשיכים לוואטסאפ. הקופון luno2 מופעל ב־Grow. יש למלא כתובת ומייל בעמוד התשלום.

אין צורך להכניס מפתחות API. האתר אינו שומר פרטי אשראי ואינו מסמן הזמנה כשולמה; אישור התשלום ומעקב העסקאות מתבצעים ב־Grow.
