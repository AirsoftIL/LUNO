# LUNO — הקבצים המעודכנים ל־GitHub

1. חלצו את קובץ ה־ZIP.
2. פתחו את המאגר LUNO ב־GitHub, בלשונית Code.
3. העלו את כל התוכן שבתיקייה: index.html, classic.html, extreme.html, tracking.html, assets, images, videos ושאר הקבצים. החליפו את הקבצים הקיימים; לא רק index.html. אין להעלות את ה־ZIP עצמו.
4. ודאו שבהגדרות Pages נבחרים הענף main ותיקיית root, ושמרו את השינויים.
5. אחרי ש־GitHub מסיים לפרסם, פתחו https://airsoftil.github.io/LUNO/ ורעננו.

אין צורך להתקין כלום. index.html טוען את הקוד מתוך assets ולכן הוא קצר — זה תקין. יש להעלות את כל התיקיות יחד.

## התשלום

המחירים: Classic ‏349 ₪, Extreme ‏399 ₪. משלוח חינם, 7–14 ימי עסקים.
כל 27 השילובים של 1–6 משקפיים מחושבים בשרת. מ־7 משקפיים מזמינים בוואטסאפ.
לפני תשלום ממלאים שם מלא, אימייל, טלפון וכתובת מלאה. הקופון luno2 נותן 10% הנחה.
לכל הזמנה חדשה נוצר קישור GROW אישי דרך Make. אין להשתמש בקישורי בדיקה עבור לקוחות אחרים.
לוגו הירח מופיע בשורת ההזמנה ב־GROW. השם העסקי בעברית עדיין נעול בחשבון GROW ולא שונה.
כל אמצעי התשלום הזמינים בחשבון מוצעים לפי המכשיר והדפדפן.

חשוב להשאיר את תרחיש LUNO checkout — Free plan ב־Make פעיל, וגם את אתר LUNO ב־Sites פעיל. GitHub הוא האתר הציבורי, ו־Sites מפעיל את יצירת התשלום ושמירת הכתובות.

Make נשאר במסלול החינמי. מוגדרות עד 300 יצירות קישור ב־32 ימים ועד 5 בשעה מאותה כתובת IP. צפייה באתר או הוספה לסל אינן צורכות Make. יצירת קישור צורכת כ־3 credits, גם אם התשלום לא הושלם. שימוש נוסף ב־Make ובדיקות צורכים מאותה מכסה. אין שדרוג אוטומטי בתשלום; במקרה של מגבלה מופיעה חלופת WhatsApp. עמלות הסליקה הרגילות של GROW נשארות לפי החשבון שלך.
